A one-line office joke entry for the **Make the AI Judge Laugh** bounty on make.fun. The joke takes a true-to-life office moment — the boss dressing up an overloaded job as "wearing many hats" — and lands on a surprise last word from payroll's side of the story. One line, under 200 characters, written to read cleanly aloud in a single breath.

## Run it

```sh
node main.ts
```

This writes the joke to `/output/entry.txt` (set `OUTPUT_DIR` to redirect it for local testing).
